# 🧀 Trivia Lusófono — versão online

Jogo de trivia para portugueses e brasileiros, em igualdade. Abre em **https://brunorscarvalho.github.io/trivia_mp/**

- **🎉 Festa online:** cria-se uma sala e envia-se o link. Cada amigo escolhe o nome e entra, sem limite de jogadores. Todos respondem às mesmas perguntas ao mesmo tempo.
- **Dois jogadores** no mesmo ecrã… ou tela, e **solo contra o Atlas 🤖**.

Site estático (GitHub Pages). O tempo real usa MQTT num broker público gratuito, por isso não há contas nem custos. O código-fonte e as ferramentas de validação estão no repo privado `trivia`. Este repo é só a cópia publicada.
